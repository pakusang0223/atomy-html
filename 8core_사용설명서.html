체크리스트 사용 설명서

파일 하나로 매일 실천을 기록하고
관리자가 한눈에 확인할 수 있는 방법을 안내합니다

📦 PART 1 — 처음 시작하기
1

📥 파일을 받아서 열기

받은 8core_checklist.html 파일을 클릭하면 브라우저(크롬, 사파리, 네이버 등)에서 바로 열립니다.
앱 설치 없이, 인터넷 연결 없이도 사용 가능합니다.

✅ 추천 브라우저: 크롬(Chrome) 또는 사파리(Safari) — 가장 안정적으로 작동합니다.
2

✍️ 이름과 월 입력하기

화면 상단에 이름과 월(월 선택)을 입력합니다.
이렇게 하면 누구의 몇 월 기록인지 구분할 수 있습니다.

📌 이름은 LINE이나 카카오에서 전송 전에 꼭 먼저 입력하도록 안내해 주세요.

💾 PART 3 — 저장과 이어쓰기
6

💾 저장하는 방법

입력 후 2초가 지나면 자동으로 저장됩니다. 화면 하단 바에서 「✓ 저장 완료」 메시지를 확인할 수 있습니다.

또는 하단의 💾 저장하기 버튼을 직접 눌러 수동으로 저장할 수 있습니다.

📌 저장은 본인 브라우저에만 저장됩니다. 파일을 다른 기기로 옮기면 데이터가 없습니다. 같은 기기·같은 브라우저에서 계속 열어 사용하세요.
7

🔄 다음에 다시 열었을 때

파일을 닫고 다시 열어도 이전에 입력한 내용이 그대로 남아 있습니다.
매달 새로 시작할 때는 「초기화」 버튼을 눌러 리셋할 수 있습니다.

✅ 한 달이 끝나면 초기화 전에 스크린샷을 찍어 보관하는 것을 추천합니다.
📤 PART 4 — 팀원에게 배포하는 방법
8

📲 LINE / 카카오톡으로 파일 전송

노션 계정 없이, 앱 설치 없이 파일 하나만 전송하면 됩니다.

1
LINE 또는 카카오톡 채팅창 열기
2
파일 첨부 버튼(📎) 클릭 → 8core_checklist.html 선택
3
전송 완료 → 받은 사람이 파일을 클릭해서 브라우저로 열기
4
각자 본인 이름 입력 후 사용 시작 — 완전 개인 독립 파일
✅ 각자 자신의 기기에서 열기 때문에 서로의 내용이 섞이지 않습니다.
9

📸 관리자에게 결과 공유하는 방법

팀원이 기록을 완성하면 아래 방법으로 관리자에게 공유합니다.

1
브라우저에서 체크리스트 전체 화면 캡처
2
LINE 또는 카카오톡 단체방에 이미지 전송
3
관리자는 메모 내용 + 배지 색상으로 즉시 확인
📌 PC에서는 Ctrl+Shift+S (윈도우) 또는 Cmd+Shift+4 (맥)으로 스크린샷 가능
❓ 자주 묻는 질문
Q 파일을 열면 아무것도 없어요. 왜 그런가요?
처음 열 때는 데이터가 없으므로 정상입니다. 이름과 월을 입력하고 체크를 시작하면 됩니다.
Q 스마트폰에서도 사용할 수 있나요?
네, 사용 가능합니다. LINE에서 파일을 받은 후 「다른 앱으로 열기」→ Safari 또는 Chrome으로 열면 됩니다. 가로 방향(가로 모드)으로 돌리면 더 보기 편합니다.
Q 저장했는데 다시 열면 내용이 없어요.
저장은 같은 기기의 같은 브라우저에서만 유지됩니다. 다른 브라우저(크롬→사파리 등)로 열거나 다른 기기에서 열면 데이터가 없습니다. 항상 같은 브라우저로 여세요.
Q 다음 달에도 같은 파일을 쓸 수 있나요?
네, 하단의 「초기화」 버튼을 누르면 모든 데이터가 삭제되고 새로 시작할 수 있습니다. 초기화 전에 반드시 스크린샷으로 기록을 보관하세요.
Q 태국어·일본어 버전은 따로 있나요?
현재 한국어 버전이 기본입니다. 태국어 버전과 일본어 버전은 별도 파일로 제공될 예정입니다. 모든 항목명·안내문·명언이 각 언어로 번역됩니다.
💡 핵심 요약

파일 받기 → 브라우저로 열기 → 이름·월 입력
→ 매일 체크 + 메모 → 자동 저장
→ 월말에 스크린샷 찍어 관리자에게 전송

궁금한 점은 리더에게 LINE 또는 카카오톡으로 문의하세요
